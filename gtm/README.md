# Paid — round-1 outreach package

This folder is the starter kit for talking to the first 10 boutique A/E firms about Paid. Every file is set up so you can execute without any more design work — just personalize and send.

## What's in here

1. **`01-targets.md`** — the 10 firms with named decision-makers, emails, LinkedIn URLs, and hooks
2. **`02-emails.md`** — 2 cold email variants (split-test) + day-3 bump + reply template
3. **`03-linkedin.md`** — day-4 LinkedIn fallback (connection note + DM + day-8 bump)
4. **`04-discovery-script.md`** — 30-minute customer discovery script for the calls you book
5. **`05-tracker.xlsx`** — spreadsheet with the 10 firms pre-loaded; Status dropdown, Log sheet, Quotes sheet

## Exact steps — first hour

Go to calendly.com → sign up free → create a 25-min event called "Paid — A/E discovery call." Set availability to your real working hours. Paste the link into `02-emails.md` under "What 'yes' looks like" before sending anything.

### Step 3 (15 min) — write 5 personalized emails using Variant A
Use the Variant A template in `02-emails.md`. For each firm, replace the `{hook}` slot with something specific from their site or LinkedIn — example for Hunter:

Drop each into Gmail Drafts. Don't send yet.

### Step 4 (15 min) — write 5 emails using Variant B for the other 5
Same drill, Variant B template, other 5 firms.

### Step 5 (5 min) — schedule sends
Use Gmail's "Schedule send" to fire all 10 between 7:30–9:00am the recipient's local time, Tuesday or Wednesday. Avoid Monday (deluge) and Friday (ignored). Mark them `emailed` in the tracker with the scheduled date.

### Step 6 (1 min) — set a reminder
Calendar reminder for **Day 4 after each send** — that's when the LinkedIn DM goes out if no reply.

## Then what

- **If 2+ replies positive** → schedule, run discovery calls per `04-discovery-script.md`. Stop sourcing new firms until those calls are done. Listen, don't pitch.
- **If 0 replies in 7 days** → the email or the targeting is off. Tell me what came back (or what didn't) and we adjust.
- **If 1 yes and 9 no/silence** → still a real signal. Run that one call hard. The first design partner is worth more than 9 polite no-replies.

## Reality check on revenue

10 emails → realistic reply rate for boutique-A/E cold-outbound is **15–25%**. So expect 2–3 replies, 1–2 calls booked, 0–1 pilot agreement. That's a win for round 1. Revenue from a $99/mo design partner = $1,188 ARR. **The first dollar is the hard one — the path from 1 to 10 customers is way easier than 0 to 1.**

If you want a faster path to revenue, the second batch (round 2) should probably be warm intros — your existing network, Twitter/LinkedIn people who liked your launch tweet, anyone you've talked to before. Tell me if you want me to mine that.
